# GlitchVisual — PS5-inspired main menu

Клиентский Fabric-мод для Minecraft Java Edition 1.21.11. Меню вдохновлено видео: космический фон, фиолетовое свечение, звёзды, лаконичная верхняя навигация и три круглые кнопки.

## Возможности прототипа
- Замена экрана главного меню Minecraft на GlitchVisual.
- Русские подписи.
- Анимированное мерцание звёзд и фиолетовые акценты.
- Кнопки «Одиночная игра», «Сетевая игра», «Настройки».
- Ссылка «Выход».
- Переход к стандартным экранам выбора мира, мультиплеера и настроек.

## Сборка
Требуется JDK 21 и Gradle. В корне проекта:
```bash
gradle build
```
Готовый JAR должен появиться в `build/libs/`.

## Важно
Это исходный прототип, не собранный и не протестированный в запущенной игре в этой среде. Если Gradle не найдёт одну из указанных версий Loom/Yarn/Fabric API, замените её на совместимую с Minecraft 1.21.11. Из-за различий в маппингах между версиями могут понадобиться небольшие правки API.

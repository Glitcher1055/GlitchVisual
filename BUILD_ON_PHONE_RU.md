# Как собрать GlitchVisual с телефона

В архив добавлен GitHub Actions workflow, который пытается собрать мод в облаке — устанавливать Java или Gradle на Android не требуется.

1. Создайте аккаунт/войдите на GitHub.
2. Создайте новый репозиторий, например `GlitchVisual`.
3. На странице репозитория нажмите Add file → Upload files и загрузите содержимое этого ZIP после распаковки.
4. Откройте вкладку Actions и выберите `Build GlitchVisual`.
5. Нажмите `Run workflow` (если запуск вручную доступен) или дождитесь сборки после загрузки файлов.
6. Откройте завершённый запуск workflow, найдите раздел Artifacts и скачайте `GlitchVisual-JAR`.
7. Извлеките JAR из скачанного архива и положите его в папку `mods` профиля Fabric 1.21.11.

Важно: это автоматизирует сборку, но не гарантирует её успешность. Если сборка завершится ошибкой, откройте логи шага `Собрать мод` и пришлите текст ошибки — исходники нужно будет исправить. Не устанавливайте файл, если артефакт не был создан успешной сборкой.
